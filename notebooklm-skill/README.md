# NotebookLM Skill para Claude Code

Acceso programatico completo a Google NotebookLM desde Claude Code, incluyendo funciones no disponibles en la interfaz web.

## Archivos

| Archivo | Descripcion |
|---------|-------------|
| `NotebookLMSkill.md` | La skill principal para Claude Code (Mac + Windows) |
| `ResumenCoNoteSkill.md` | Skill de resumen de sesion con exportacion a NotebookLM |
| `instalar_NotebookLMSkill_windows.bat` | Instalador automatico para Windows |

## Instalacion rapida

### Windows

1. Ejecuta `instalar_NotebookLMSkill_windows.bat`
2. Sube `NotebookLMSkill.md` como skill en Claude Code
3. Escribe `instala notebooklm` para autenticarte con Google

### Mac / Linux

Escribe directamente en Claude Code: `instala notebooklm`
