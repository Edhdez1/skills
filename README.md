# Skills

Coleccion de skills para Claude Code y Claude Cowork.

## Skills disponibles

| Skill | Descripcion | Plataforma |
|-------|-------------|------------|
| [NotebookLMSkill](notebooklm-skill/) | Acceso completo a Google NotebookLM desde Claude — crear cuadernos, añadir fuentes, generar podcasts, videos, infografias, presentaciones, quizzes, mapas mentales, informes y mas. | Claude Code (Mac + Windows) |
| [ResumenCoNoteSkill](notebooklm-skill/ResumenCoNoteSkill.md) | Resumen de sesion con exportacion automatica a NotebookLM. | Claude Code / Cowork |
| [Kit Cerebro Operativo](kit-cerebro-operativo/) | Sistema para convertir Cowork en tu asistente personal real — con identidad, contexto y memoria propios. | Claude Cowork |

## Como usar

### NotebookLMSkill

1. Ejecuta `instalar_NotebookLMSkill_windows.bat` (Windows) o sigue las instrucciones del README
2. Sube `NotebookLMSkill.md` como skill en Claude Code
3. Escribe `instala notebooklm` para autenticarte

### Kit Cerebro Operativo

1. Crea una carpeta `SegundoCerebro/` en tu ordenador
2. Abre Cowork y monta esa carpeta
3. Sigue los 5 pasos del kit en orden (cada prompt te guia al siguiente)
